# 카카오톡 채널에 AI 상담 연결하기 (사장님용)

손님이 우리 샵 카카오톡 채널에 말을 걸면, 겨울파트너가 안내 정보(가격·영업시간·위치·규정)로 바로 답하고, 예약·흥정·불만처럼 사장님이 봐야 하는 문의는 "사장님께 전달했어요"라고 답한 뒤 사장님께 넘깁니다.

준비하는 데 30분쯤 걸립니다. 카카오 쪽 화면 이름은 바뀔 수 있어서, 화면이 다르면 비슷한 메뉴를 찾아 주세요. **"확인 필요"** 라고 적힌 곳은 아직 실제 화면에서 확인하지 못한 부분입니다(시범 연결 P22-8 때 함께 확인합니다).

> 연결 화면(우리 서비스 안에서 버튼으로 연결)은 다음 단계(P22-5·P22-8)에서 만듭니다. 지금은 **본사가 웹훅 주소(토큰)를 만들어 알려 드립니다.**

---

## 1. 카카오톡 채널 만들기

1. 컴퓨터에서 **카카오톡 채널 관리자센터**(center-pf.kakao.com)에 들어가 카카오 계정으로 로그인합니다.
2. **새 채널 만들기**를 누르고 채널 이름(예: 하이원 스노우렌탈), 검색용 아이디, 프로필 사진을 넣습니다.
3. 채널을 **공개**로 두고, **검색 허용**을 켭니다.
4. **비즈니스 채널**로 바꿉니다. 채널 관리자센터 → 채널 설정 → 비즈니스 정보에서 사업자등록증을 올려 신청합니다. 심사는 보통 며칠 걸립니다. (확인 필요: 챗봇 연결에 비즈니스 채널이 꼭 필요한지)

## 2. 카카오 i 오픈빌더(챗봇 관리자센터)에서 봇 만들기

1. **카카오 i 오픈빌더**(chatbot.kakao.com)에 들어가 같은 카카오 계정으로 로그인합니다. 처음이면 이용 신청을 합니다. (확인 필요: 신청 뒤 승인까지 걸리는 시간)
2. **봇 만들기** → **카카오톡 챗봇**을 고르고 봇 이름을 넣습니다.
3. 왼쪽 메뉴 **설정** → **카카오톡 채널 연결**에서 1번에서 만든 채널을 고르고 연결합니다.
4. **봇 id를 본사에 알려 주세요.** 봇 화면 주소(인터넷 주소창)의 `.../bot/` 뒤에 있는 영어·숫자가 봇 id입니다. 우리 서버는 요청에 들어 있는 봇 id가 이 값과 같을 때만 답합니다. (확인 필요: 주소창 값과 요청 속 봇 id가 같은지 시범 때 확인)

## 3. 스킬 서버 주소 등록

"스킬"은 손님 말을 받아 우리 서버에 물어보는 연결입니다.

1. 본사에서 받은 **웹훅 주소**를 준비합니다. 모양은 이렇습니다.
   ```
   https://winter-partner.vercel.app/api/webhooks/kakao/<토큰>
   ```
   `<토큰>`은 영어 소문자·숫자 48자리입니다. **이 주소는 비밀번호처럼 다른 사람에게 보여 주지 마세요.** 새어 나가면 본사에 말해 주시면 새 주소로 바꿔 드립니다.
2. 오픈빌더 왼쪽 메뉴 **스킬** → **생성**을 누릅니다.
3. 이름은 `겨울파트너 AI 상담`, URL에 위 주소를 그대로 붙여 넣고 **저장**합니다.
4. 헤더 값·기본 스킬 설정은 건드리지 않아도 됩니다.

## 4. 폴백 블록에 스킬 연결

"폴백 블록"은 챗봇이 알아듣지 못한 모든 말을 받는 곳입니다. 여기에 스킬을 걸면 손님의 모든 질문이 우리 서버로 옵니다.

1. 왼쪽 메뉴 **시나리오** → **기본 시나리오** → **폴백 블록**을 엽니다.
2. 아래쪽 **파라미터 설정**에서 스킬을 **겨울파트너 AI 상담**으로 고릅니다.
3. **봇 응답**에서 **스킬데이터 사용**을 고릅니다. (직접 쓴 답변 말풍선이 있으면 지웁니다)
4. **저장**합니다.
5. 웰컴 블록(처음 들어왔을 때 인사)은 그대로 두셔도 됩니다.

## 5. 블록 "콜백" 켜기

AI 답이 3.5초 안에 나오지 않으면, 우리 서버는 먼저 "답변을 준비하고 있어요…"라고 보내고 답이 나오면 이어서 보냅니다. 이것을 **콜백**이라고 하고, 블록마다 켜야 합니다.

1. 폴백 블록 화면 오른쪽 위 설정(톱니바퀴)에서 **Callback 설정**을 켭니다.
2. 메뉴가 보이지 않으면 **AI 챗봇 전환 신청**이 먼저 필요할 수 있습니다. 오픈빌더 **설정** → **AI 챗봇 관리**에서 신청합니다. (확인 필요: 신청 절차와 심사 기간)
3. 콜백을 켜지 않아도 동작은 합니다. 다만 답이 늦은 경우 손님에게는 "사장님께 전달했어요"만 가고, AI 답은 사장님 화면에 초안으로 남습니다.

## 6. 상담 연결(사장님과 직접 채팅) 버튼

사람이 봐야 하는 문의에는 **상담 연결** 버튼이 함께 갑니다. 손님이 누르면 채널 1:1 채팅으로 넘어갑니다.

1. 카카오톡 채널 관리자센터 → **1:1 채팅**을 켭니다.
2. 오픈빌더 **스킬/플러그인** 메뉴에서 **상담 연결 플러그인**을 추가합니다. (확인 필요: 메뉴 이름과 위치)
3. 플러그인이 없으면 버튼을 눌러도 아무 일이 일어나지 않을 수 있습니다. 그래도 손님은 채널 채팅창에 바로 글을 쓸 수 있습니다.

> 카카오 무료 챗봇은 손님이 말을 걸 때만 답할 수 있고, 먼저 메시지를 보낼 수 없습니다. 사장님 답장은 **카카오톡 채널 1:1 채팅**에서 직접 보내 주세요.

## 7. 배포

1. 오픈빌더 왼쪽 메뉴 **배포**에서 **배포**를 누릅니다. 설정을 바꿀 때마다 다시 배포해야 손님에게 적용됩니다.
2. 배포가 끝나면 휴대폰 카카오톡에서 우리 채널을 찾아 "강습료 얼마예요?"처럼 물어봅니다.

## 8. 테스트할 때 알아 둘 것

- 오픈빌더 화면의 **봇 테스트**(오른쪽 말풍선 창)에서는 **콜백이 동작하지 않습니다.** 답이 늦은 질문은 봇 테스트에서 실패처럼 보일 수 있습니다. 콜백은 **배포한 채널**에서만 확인할 수 있습니다.
- 처음 자동 답변에는 "이 답변은 AI가 샵 안내 정보로 드리는 자동 답변이에요…" 고지가 붙습니다. 문구는 겨울파트너 **AI 상담 안내 정보** 화면에서 바꿀 수 있습니다.
- AI가 바로 답하려면 겨울파트너 **AI 상담 안내 정보** 화면에서 ① 안내 정보를 채워 "AI 답변에 사용"으로 켜고 ② **AI 자동 응대 켜기**를 눌러야 합니다. 꺼 두면 모든 질문이 "사장님께 전달했어요"로 갑니다.
- 같은 손님이 10분에 20번 넘게 보내거나 샵 전체가 10분에 300번을 넘으면, 잠시 자동 답변을 쉬고 상담 연결 안내만 보냅니다.

## 문제가 생기면

| 보이는 것 | 확인할 것 |
|---|---|
| "지금은 자동 상담을 받을 수 없어요" | 웹훅 주소(토큰)가 맞는지, 본사가 채널을 켰는지, 봇 id를 본사에 알렸는지 |
| 늘 "사장님께 전달했어요"만 나옴 | AI 자동 응대가 켜져 있는지, 안내 정보를 "AI 답변에 사용"으로 켰는지 |
| "답변을 준비하고 있어요…" 뒤에 아무것도 안 옴 | 콜백이 켜져 있는지(5번), 봇 테스트가 아니라 배포한 채널에서 했는지 |
| 상담 연결 버튼이 안 눌림 | 1:1 채팅과 상담 연결 플러그인(6번) |

## 참고 (개발용)
- 서버: `src/app/api/webhooks/kakao/[token]/route.ts`, 흐름 `src/lib/channels/kakao/webhook.ts`, 응답 형식 `src/lib/channels/kakao/format.ts`.
- 공식 문서: [AI 챗봇 콜백 가이드](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/ai_chatbot_callback_guide), [응답 형식](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/answer_json_format).
- 콜백 주소는 손님 요청 본문에 들어오므로 `https://*.kakao.com`만 허용한다(실제 도메인은 시범 때 확인 필요). E2E의 가짜 콜백 서버(localhost)는 `KAKAO_CALLBACK_ALLOW_LOCAL=1`일 때만 — 운영 환경변수에는 넣지 않는다.
- `CONSULT_HASH_KEY`가 없으면 웹훅은 아무것도 저장하지 않고 기본 안내만 보낸다(기능 꺼짐).
