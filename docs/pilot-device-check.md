# 실제 기기 점검표 (시범 샵 전)

자동 테스트는 컴퓨터 브라우저로만 돌았습니다. 아래는 **사람이 실제 휴대폰으로** 확인해야 하는 것입니다. 운영 주소(`https://winter-partner.vercel.app`)에서 `[테스트]` 계정으로만 합니다(계정 목록은 `docs/test-data-cleanup.md`, 비밀번호는 따로 전달).

**준비할 기기**: 아이폰(iOS 16.4 이상, 사파리) 1대, 안드로이드(크롬) 1대. 가능하면 강사 역할 기기와 샵 역할 기기를 나눕니다(한 사람이 노트북으로 샵, 휴대폰으로 강사).

## A. 아이폰 사파리 — 홈 화면 앱(PWA)
아이폰은 **홈 화면에 추가한 뒤에만** 웹푸시가 됩니다.
1. 사파리로 운영 주소 열기 → `[테스트]` 강사 계정 로그인
2. 공유 버튼 → **홈 화면에 추가** → 이름 "겨울파트너" 그대로 → 추가
3. 홈 화면 아이콘으로 열기: 주소창 없이 앱처럼 열리는지, 아이콘이 깨지지 않는지
4. 알림 → **알림 켜기** → "허용" (사파리 창이 아니라 홈 화면 앱 안에서)
5. 노트북(샵 계정)에서 그 강사에게 직접 의뢰 보내기 → 휴대폰 잠금 화면에 알림이 뜨는지(1분 안)
6. 알림을 누르면 앱이 열리고 의뢰 화면으로 가는지
7. 비행기 모드 켜고 앱 열기 → "연결 없음" 안내 화면이 나오는지 → 다시 끄면 정상
8. 정산 탭 → 정산서 PDF 열기: 한글이 깨지지 않는지, 공유 → 프린트(미리보기)까지

## B. 안드로이드 크롬
1. 크롬으로 운영 주소 → `[테스트]` 강사 로그인
2. 메뉴 ⋮ → **앱 설치**(또는 홈 화면에 추가) → 아이콘으로 열기
3. 알림 켜기 → 허용 → 샵에서 의뢰 보내기 → 알림 도착·누르면 해당 화면
4. 강습 완료 보고 화면 → **말로 입력** → 마이크 허용 → "오늘 처음 타셨고 턴 연습했어요" 말하기 → 글자로 들어오는지, 인식이 쓸 만한지
5. 비행기 모드 오프라인 화면
6. 정산서 PDF 열기·다운로드 폴더 저장

## C. QR 셀프 등록 (샵 노트북 + 아무 휴대폰)
1. 샵 계정 → 손님 → **QR 셀프 등록** → 링크 만들기 → 화면의 QR을 종이에 인쇄(또는 화면 그대로)
2. 휴대폰 **기본 카메라 앱**으로 QR 찍기 → 뜨는 링크 누르기 → 브라우저에서 등록 화면이 열리는지
3. `[테스트] 기기점검손님`, 휴대폰 `010-0000-9xxx`로 등록 → 샵 손님 목록에 생기는지
4. 같은 QR로 두 번째 등록이 되는지(링크 유효 기간·횟수 안내와 맞는지)

## D. 링크 미리보기 (동의 링크)
1. 14세 미만 `[테스트]` 손님 → 보호자 동의 링크 만들기 → 본인 카톡 "나와의 채팅"과 문자로 보내기
2. 미리보기에 개인정보(이름·연락처)가 보이지 않는지, 누르면 동의 화면이 열리는지

## E. 메일 (메일 설정 뒤, `docs/mail-setup.md` 7단계)
1. 지메일·네이버 메일로 [테스트] 가입 → 인증 메일이 받은편지함에 오는지
2. 비밀번호 재설정 메일 → 새 비밀번호로 로그인
