# 샵 탈퇴 시 손님 데이터 내보내기·파기 절차 (초안 — 법률 검토 전)

손님 정보의 처리자(주인)는 각 샵이고, 겨울파트너는 샵의 위탁을 받아 처리하는 수탁자다.
샵이 탈퇴하면 위탁 계약이 끝나므로, 겨울파트너는 샵이 요청한 방식으로 손님 정보를 돌려주고 파기한다.

## 1. 탈퇴 요청 접수
- 샵 대표(사업자 명의자)가 본사에 서면(이메일)으로 요청한다. 본사는 사업자등록번호와 가입 계정으로 본인 확인을 한다.
- 진행 중이거나 정산이 끝나지 않은 강습이 있으면 먼저 정리한다(취소 또는 정산 지급 완료 표시).

## 2. 내보내기 (샵이 원할 때)
- 본사가 그 샵의 손님 목록(이름·연락처·보호자·레벨·장비·태그·메모·다음 연락), 강습 이력, 선택 동의 기록(시각·방법·문구 버전·주체)을
  Excel(.xlsx)로 만들어 샵 대표에게 전달한다. 파일은 암호를 걸고, 암호는 다른 경로(문자)로 보낸다.
- 정산서(PDF)·정산 Excel은 샵이 탈퇴 전에 직접 내려받도록 안내한다(세무 자료 보관 의무는 샵에 있다).
- 내보내기는 접속 기록(손님 목록 다운로드)에 남긴다.

## 3. 파기
- 내보내기 확인 후(또는 요청일로부터 30일 뒤) 그 샵의 모든 손님을 익명화한다: `private.anonymize_customer` (사유 retention 또는 request).
  - 이름·연락처·보호자·출생 연도·장비·태그·메모·다음 연락, 연락 기록, 동의 링크, 일행 연결, 강습 요청 사항·수업 메모가 지워진다.
- 등록 링크(QR)를 모두 폐기하고 샵 멤버 계정의 샵 연결을 끊는다.
- 법령상 보관해야 하는 것(정산·지급 기록 등 거래 기록)은 해당 기간 동안 분리 보관한 뒤 파기한다. 기간은 법률 검토로 확정한다.
- 접속 기록은 보관 기간(2년)이 지나면 자동 정리된다.
- 백업에 남은 데이터는 백업 보관 주기(Supabase 설정)가 지나면 사라진다. 이 기간을 처리방침에 적는다.

## 4. 완료 통지
- 파기 일시와 범위를 샵 대표에게 이메일로 알린다. 본사는 처리 내역(요청일·내보내기일·파기일·담당자)을 기록해 둔다.

## 아직 정할 것 (사장님·법률 검토)
- 내보내기 후 파기까지의 기간(현재 초안 30일)
- 거래 기록의 법정 보관 기간과 대상
- 탈퇴 요청 서식과 본인 확인 방법
