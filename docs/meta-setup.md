# 인스타그램 DM에 AI 상담 연결하기 — 메타 앱 준비 (사장님용)

손님이 샵 인스타그램에 DM을 보내면, 겨울파트너가 안내 정보(가격·영업시간·위치·규정)로 바로 답하고, 예약·흥정·불만처럼 사장님이 봐야 하는 문의는 "사장님께 전달했어요"라고 답한 뒤 사장님께 넘깁니다.

이 문서는 **본사(사장님)가 한 번만** 하는 준비입니다. 메타(인스타그램 회사)에 "우리 서비스가 샵 인스타 DM을 대신 받고 답해도 된다"는 허락을 받는 과정입니다. 준비가 끝나면 각 렌탈샵은 안내 정보 화면에서 **[인스타그램 연결하기]** 버튼만 누르면 됩니다.

- 걸리는 시간: 서류·영상 준비 하루 정도 + 메타 심사 **며칠~몇 주**(확인 필요 — 메타 사정에 따라 다릅니다). **일찍 시작해 주세요.**
- 비용: 없음(메타 개발자 계정·앱·심사는 무료).
- 메타 화면 이름은 자주 바뀝니다. 화면이 다르면 비슷한 메뉴를 찾아 주세요. **"확인 필요"** 라고 적힌 곳은 아직 실제 화면에서 확인하지 못한 부분입니다.
- 비밀값(앱 시크릿 등)은 **이 문서·카톡·메일에 적지 마세요.** Vercel 환경변수에만 넣습니다.

## 0. 미리 준비할 것

| 준비물 | 어디에 쓰나 |
|---|---|
| 페이스북 개인 계정 (본사 대표 명의) | 메타 개발자 계정 로그인 |
| 사업자등록증 (PDF 또는 사진) | 비즈니스 인증 |
| 사업장 주소·대표 전화번호·회사 메일 주소 | 비즈니스 인증 |
| 회사 홈페이지 주소: `https://winter-partner.vercel.app` | 앱 정보, 비즈니스 인증 |
| 개인정보 처리방침 주소: `https://winter-partner.vercel.app/privacy` | 앱 정보·심사 (AI 상담 문구는 법률 검토 후 추가 — docs/ai-consult/README.md "개인정보 문구 초안") |
| 시험용 인스타그램 **프로페셔널(비즈니스 또는 크리에이터) 계정** 1개 | 심사용 시연 영상. 개인 계정이면 인스타 앱 → 설정 → 계정 유형에서 "프로페셔널 계정으로 전환" |
| 휴대폰 화면 녹화 + 컴퓨터 화면 녹화 | 심사용 시연 영상 |

## 1. 메타 개발자 계정·앱 만들기

1. 컴퓨터에서 **developers.facebook.com** 에 들어가 페이스북 계정으로 로그인합니다.
2. 처음이면 **시작하기**를 눌러 개발자로 등록합니다(전화번호·메일 확인).
3. 위쪽 **내 앱** → **앱 만들기**를 누릅니다.
4. 사용 사례를 고르는 화면이 나오면 **"기타"** → 앱 유형 **"비즈니스(Business)"** 를 고릅니다. (확인 필요: 화면에 "Instagram 메시지 관리" 같은 사용 사례가 바로 있으면 그것을 골라도 됩니다)
5. 앱 이름: `겨울파트너`, 연락처 메일: 회사 메일. 비즈니스 포트폴리오(비즈니스 관리자 계정)가 있으면 연결하고, 없으면 나중에 2번에서 만듭니다.
6. 앱이 만들어지면 **앱 설정 → 기본 설정**에서 아래를 채우고 저장합니다.
   - 개인정보 처리방침 URL: `https://winter-partner.vercel.app/privacy`
   - 서비스 약관 URL: `https://winter-partner.vercel.app/terms`
   - **사용자 데이터 삭제**: "데이터 삭제 안내 URL"을 고르고 `https://winter-partner.vercel.app/privacy` (처리방침에 "샵이 연결을 해제하면 토큰을 지우고, 상담 기록은 90일 뒤 삭제" 문구가 들어가야 합니다 — 법률 검토 항목)
   - 앱 아이콘(1024×1024), 카테고리: 비즈니스·생산성
7. 같은 화면 위쪽의 **앱 ID**와 **앱 시크릿 코드**(보기 → 비밀번호 확인)를 확인합니다. **앱 시크릿은 아무 데도 적지 말고** 6번(Vercel)에서 바로 붙여 넣습니다.

## 2. Instagram 제품 추가 (Instagram 로그인 방식)

1. 앱 대시보드 왼쪽 **제품 추가**(또는 "사용 사례") → **Instagram** → **설정**을 누릅니다.
2. **"Instagram 로그인을 통한 API 설정"(API setup with Instagram login)** 을 고릅니다. 페이스북 로그인 방식이 아닙니다(사장님 결정: 렌탈샵이 페이스북 페이지를 만들 필요가 없게).
3. 화면에 나오는 **Instagram 앱 ID·Instagram 앱 시크릿**이 1번의 앱 ID·시크릿과 다를 수 있습니다. **이 화면의 인스타그램용 값**을 6번 환경변수에 넣습니다. (확인 필요: 두 값이 다르게 나오는지)
4. **비즈니스 로그인 설정**(Set up Instagram business login)에서
   - **리디렉션 URL(OAuth 리디렉션 URI)**: `https://winter-partner.vercel.app/api/channels/instagram/callback` 을 넣고 저장합니다. 한 글자라도 다르면 연결이 실패합니다.
   - 권한: `instagram_business_basic`, `instagram_business_manage_messages` 두 개만 씁니다.
5. **역할 → Instagram 테스터**에 시험용 인스타 계정을 추가하고, 그 인스타 계정에서 초대를 수락합니다(인스타 앱 → 설정 → 앱 및 웹사이트 → 테스터 초대). 심사 전에는 **테스터로 등록한 계정만** 연결됩니다.

## 3. 웹훅 주소 등록

웹훅은 "손님 DM이 오면 메타가 우리 서버에 알려 주는 연결"입니다.

1. 먼저 6번(Vercel 환경변수)을 끝내고 배포가 끝났는지 확인합니다. 우리 서버가 확인 요청에 답해야 등록됩니다.
2. Instagram 제품 화면의 **웹훅 구성(Configure webhooks)** 에서
   - **콜백 URL**: `https://winter-partner.vercel.app/api/webhooks/instagram`
   - **확인 토큰(Verify token)**: 사장님이 정한 아무 긴 문자열(영어·숫자 30자 이상 추천). 6번의 `META_VERIFY_TOKEN`과 **똑같이** 넣습니다. 이 값도 문서에 적지 않습니다.
   - **확인 및 저장**을 누릅니다. 실패하면 환경변수 3개가 모두 들어갔는지, 배포가 끝났는지 확인합니다.
3. 구독할 필드에서 **messages** 를 켭니다. (`messaging_seen`·`message_reactions` 등은 켜지 않아도 됩니다. 켜도 우리 서버는 무시합니다)
4. 샵이 [인스타그램 연결하기]를 누르면 우리 서버가 그 샵 계정의 메시지 웹훅 구독을 자동으로 켭니다. (확인 필요: 첫 시험 때 메타 화면에서 구독이 켜졌는지 확인)

## 4. 비즈니스 인증

다른 사람(렌탈샵)의 인스타 계정을 연결하려면 메타가 "실제 회사"인지 확인해야 합니다.

1. **business.facebook.com** → 설정 → **비즈니스 정보** → **보안 센터** → **인증 시작**을 누릅니다. 비즈니스 포트폴리오가 없으면 여기서 먼저 만들고, 1번 앱을 이 포트폴리오에 연결합니다(앱 설정 → 기본 설정 → 비즈니스 포트폴리오).
2. 준비물: **사업자등록증**, 회사 이름(사업자등록증과 똑같이), 주소, 전화번호, 홈페이지 주소, 회사 메일.
3. 메타가 회사 메일·전화·문자로 확인 코드를 보내면 입력합니다.
4. 걸리는 시간: 보통 며칠, 서류가 맞지 않으면 다시 요청이 옵니다(확인 필요).

## 5. 앱 검수 — Advanced Access 신청

심사를 통과해야 테스터가 아닌 **모든 렌탈샵 계정**을 연결할 수 있습니다.

1. 앱 대시보드 → **앱 검수(App Review)** → **권한 및 기능**에서 아래 두 권한의 **Advanced Access(고급 액세스)** 를 요청합니다.
   - `instagram_business_basic` — 연결한 계정의 id·이름 확인
   - `instagram_business_manage_messages` — 손님 DM 받기·답하기
2. 권한마다 적는 칸(영어로 쓰는 것이 안전합니다, 아래 예시를 그대로 써도 됩니다):
   - 사용 목적 예시: *"Ski rental shops connect their Instagram professional account to our platform. When a customer sends a DM, we reply with the shop's own published information (prices, hours, location, policy). Bookings, negotiations and complaints are forwarded to the shop owner, who replies personally. We only reply within the 24-hour messaging window."*
   - 개인정보 처리방침 URL(1번과 같음).
3. **화면 녹화 시연 영상**(권한마다 1개, 몇 분 이내, 소리 없어도 됨). 시험용 인스타 계정으로 아래 순서를 한 번에 찍습니다.
   1. 겨울파트너 샵 관리자로 로그인 → AI 상담 안내 정보 화면 → **[인스타그램 연결하기]** 클릭
   2. 인스타그램 로그인·권한 허용 화면 → 허용 → 겨울파트너로 돌아와 "연결됨" 표시
   3. 다른 휴대폰(손님 역할)에서 그 인스타 계정으로 "강습료 얼마예요?" DM → AI 답장이 오는 모습
   4. "12월 20일 2명 예약돼요?" DM → "사장님께 전달했어요" 답장 + 겨울파트너 화면에 문의가 생긴 모습
   5. 안내 정보 화면에서 **[연결 해제]** 를 누르는 모습
4. **데이터 삭제 안내**: 1번 6에서 넣은 주소. 처리방침에 "연결 해제 시 토큰 삭제, 상담 기록 90일 뒤 삭제, 삭제 요청은 본사 메일로"가 있어야 합니다.
5. 제출하면 메타가 며칠~몇 주 뒤 결과를 메일로 보냅니다(확인 필요). 거절되면 사유를 읽고 영상·설명을 고쳐 다시 냅니다. 거절 메일을 본사 개발 담당(Claude 작업)에게 그대로 전달해 주시면 고칠 곳을 정리해 드립니다.

## 6. Vercel 환경변수 넣기

**Vercel → winter-partner 프로젝트 → Settings → Environment Variables** 에서 **Production**에 아래 이름으로 넣고, 넣은 뒤 **다시 배포(Redeploy)** 합니다. 값은 여기 적지 않습니다.

| 이름 | 값 |
|---|---|
| `META_APP_ID` | 2번 3의 Instagram 앱 ID |
| `META_APP_SECRET` | 2번 3의 Instagram 앱 시크릿 |
| `META_VERIFY_TOKEN` | 3번 2에서 정한 확인 토큰 (같은 값) |

- `CONSULT_ENCRYPTION_KEY`·`CONSULT_HASH_KEY`(P22-1)도 있어야 합니다. 하나라도 없으면 인스타 기능은 **꺼진 상태**(화면에 "준비 중", 웹훅 주소는 404)로 안전하게 남습니다.
- `META_HUMAN_AGENT` = `1` 은 **7번 Human Agent 승인을 받은 뒤에만** 넣습니다. 없으면 손님 마지막 메시지 후 24시간이 지난 대화는 사장님도 겨울파트너에서 보낼 수 없고, 인스타 앱에서 직접 답해야 합니다.
- `META_GRAPH_API_VERSION`은 넣지 않아도 됩니다(기본 v24.0). 메타가 이 버전을 더 이상 받지 않는다고 하면 그때 넣습니다(확인 필요).

## 7. Human Agent 기능 신청 (선택, 나중에)

인스타는 손님 마지막 메시지 후 **24시간** 안에만 답할 수 있습니다. **Human Agent** 승인을 받으면 **사람(사장님)이 직접 쓴 답장**에 한해 **7일**까지 보낼 수 있습니다.

1. 앱 검수 → 권한 및 기능에서 **Human Agent** 를 찾아 요청합니다. (확인 필요: Instagram 로그인 방식 앱에서도 같은 이름·같은 규칙인지 — 신청 화면에서 확인)
2. 사용 목적 예시: *"Shop owners reply personally to customer inquiries (bookings, changes) from our inbox. Automated replies are never sent after 24 hours."*
3. 시연 영상: 24시간이 지난 대화에서 사장님이 인박스(P22-5)에서 답을 확인하고 **승인·발송**을 누르는 모습.
4. 승인되면 6번에 `META_HUMAN_AGENT=1`을 넣습니다. 우리 서버는 **자동 답변에는 절대 이 태그를 쓰지 않습니다**(자동화에 쓰면 메타 정책 위반). 사장님이 승인 버튼을 누른 답장에만 씁니다.

## 8. 연결 시험 (승인 전에도 테스터 계정으로)

1. 겨울파트너에 샵 관리자로 로그인 → **AI 상담 안내 정보** 화면 → "인스타그램 DM" 칸의 **[인스타그램 연결하기]**.
2. 테스터 인스타 계정으로 로그인·허용 → "인스타그램을 연결했습니다"가 보이면 성공.
3. 다른 계정에서 DM "강습료 얼마예요?" → AI 자동 응대가 켜져 있고 안내 정보에 강습료가 켜져 있으면 답이 옵니다.
4. 연결 토큰은 약 60일짜리이고, 매일 정리 작업이 만료 7일 전에 자동으로 새로 받습니다(확인 필요: 메타 문서의 갱신 조건 — 발급 24시간 뒤부터, 만료 전에만). 만료되면 화면에 "다시 연결해 주세요"가 뜹니다.

## 막히면

- **웹훅 "확인 및 저장"이 실패**: 환경변수 3개가 Production에 있는지, 넣은 뒤 다시 배포했는지, 확인 토큰이 똑같은지.
- **연결 버튼이 안 보이고 "준비 중"**: 환경변수(`META_*` 3개, `CONSULT_*` 2개) 중 빠진 것이 있습니다.
- **"연결 시간이 지났습니다"**: 버튼을 누르고 10분 안에 인스타 로그인을 끝내야 합니다. 다시 눌러 주세요.
- **"이미 다른 샵에 연결되어 있습니다"**: 인스타 계정 하나는 샵 하나에만 연결됩니다. 원래 샵에서 [연결 해제] 후 다시.
- **DM에 답이 안 옴**: 테스터 계정인지(심사 전), 3번 3의 messages 구독, 안내 정보 화면의 "AI 자동 응대 켜짐", 안내 정보 "AI 답변에 사용" 켜짐을 확인합니다. 예약·흥정 같은 질문은 원래 AI가 답하지 않고 사장님께 넘깁니다.
- **메타 심사·비즈니스 인증 문의**: developers.facebook.com → 오른쪽 위 **도움말(지원)** → 개발자 지원, 또는 비즈니스 지원 센터(business.facebook.com/business/help). 거절 메일은 개발 담당에게 전달해 주세요.
- 화면 이름이 이 문서와 다르면 캡처해서 전달해 주세요. 문서를 고치겠습니다.

## 기술 메모 (개발용)

- 웹훅 `GET/POST /api/webhooks/instagram`: GET은 `hub.verify_token` 대조 후 `hub.challenge`(글자), POST는 원문 바이트 `X-Hub-Signature-256` 검증(실패 400) → 200 → `after()` 처리. 코드 `src/lib/channels/instagram/`.
- 연결 `GET /api/channels/instagram/connect` → 인스타 로그인 → `GET /api/channels/instagram/callback`(state 서명 + nonce 쿠키 + 세션 대조) → 짧은 토큰 → 장기 토큰(`ig_exchange_token`) → `me?fields=user_id,username` → `me/subscribed_apps?subscribed_fields=messages` → 암호화 저장(`consult_connect_instagram`). 확인 필요: 엔드포인트·응답 모양·계정 id가 웹훅 `recipient.id`와 같은지 — 첫 테스터 연결 때 확인.
- 토큰 갱신 `refresh_access_token?grant_type=ig_refresh_token`(매일 `api/maintenance/daily`). 확인 필요: 만료(60일)·갱신 조건.
