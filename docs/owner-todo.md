# 사장님이 직접 하실 일 (오래 걸리는 순서)

외부 가입·심사·설정·결정처럼 제가 대신 할 수 없는 일만 모았습니다. **기다리는 시간이 긴 것부터** 적었으니 위에서부터 일찍 시작해 주세요.
걸리는 시간은 2026-11 기준 대략치이고, 확실하지 않은 것은 "확인 필요"로 적었습니다. 비밀값(키·비밀번호)은 문서나 대화에 붙여 넣지 말고 각 사이트 화면에만 넣어 주세요.

끝나면 저에게 "○○ 끝"이라고만 알려 주시면 그다음 작업(코드·확인)을 제가 이어서 합니다.

작성: 2026-11-05 · 작업 번호는 `docs/tasks.json` 기준

## 1. 메타(인스타그램) 개발자 앱·비즈니스 인증·앱 심사
- **무엇을**: 메타 개발자 앱 만들기 → 비즈니스 인증(사업자 서류) → 앱 심사에서 Advanced Access(`instagram_business_basic`, `instagram_business_manage_messages`)와 Human Agent 권한 신청. 심사 전에는 앱에 등록한 테스트 계정에서만 인스타 DM이 됩니다.
- **어디서**: developers.facebook.com → 내 앱 → 앱 만들기 / business.facebook.com → 설정 → 보안 센터(비즈니스 인증) / 앱 대시보드 → 앱 검수.
- **얼마나**: 비즈니스 인증 수일, 앱 심사 수 주 (확인 필요 — 반려되면 다시 제출). 심사에는 화면 녹화 영상이 필요할 수 있어, 인스타 연결 화면(P22-4)이 만들어진 뒤 제출합니다. **앱 만들기·비즈니스 인증은 지금 시작**하시는 게 좋습니다.
- **끝났다는 신호**: 앱 대시보드에서 두 권한이 "Advanced Access", 비즈니스 인증 "인증됨".
- **막히면**: 메타 비즈니스 지원 센터(business.facebook.com 도움말 → 지원 문의).
- 관련: `docs/ai-consult/README.md` "사장님이 처리할 것" 1·2, 사장님 결정 1.

## 2. 법률 검토 의뢰
- **무엇을**: `docs/legal-review-packet.md`를 변호사님께 보내고 회신(질문 24개)을 받습니다. 개인정보 보호책임자(성명·직책·연락처), 겨울파트너 사업자 정보, 처리방침 시행일도 함께 정해 주세요.
- **어디서**: 개인정보·IT 전문 변호사(법무법인 또는 개인 사무실).
- **얼마나**: 2~4주 (변호사 일정에 따름, 확인 필요). 시범 샵 실제 사용(11월 말) 전에 최소한 "시범 전에 꼭 필요한 것"만이라도 받아야 합니다.
- **끝났다는 신호**: 질문별 회신 문서. 받으시면 저에게 주시면 문구를 고치고 버전을 올립니다.
- **막히면**: 대한변호사협회 변호사 찾기, 또는 개인정보 침해신고센터(국번 없이 118, 일반 안내만).
- 관련: P13-7, P14-5, P21-9, P22(AI 상담), `docs/shop-offboarding.md` "아직 정할 것".

## 3. 카카오 알림톡 발신 프로필
- **무엇을**: 사업자 명의로 카카오톡 채널을 만들고 알림톡 발신 프로필을 신청합니다. 알림톡은 대행사(딜러사)를 통해 보내므로 대행사도 고릅니다. 승인 전까지는 웹푸시로 알립니다.
- **어디서**: 카카오톡 채널 관리자센터(center-pf.kakao.com) → 채널 만들기 → 비즈니스 인증 / 알림톡 대행사 사이트에서 발신 프로필 등록·템플릿 심사.
- **얼마나**: 채널 비즈니스 인증 수일, 발신 프로필·템플릿 심사 수일 (확인 필요).
- **끝났다는 신호**: 대행사 화면에 발신 프로필 "승인", 템플릿 "승인". 대행사 API 키는 저에게 말하지 말고 Vercel에 넣어 주세요(이름은 그때 알려 드립니다).
- **막히면**: 카카오 비즈니스 고객센터, 알림톡 대행사 담당자.
- 관련: P8-1 (blocked: "사업자 명의로 사장님이 신청해야 함").

## 4. 보호자 휴대폰 문자 인증 서비스
- **무엇을**: 14세 미만 손님의 보호자 동의를 휴대폰 본인 확인으로 받으려면 문자 인증(본인 확인) 서비스 가입이 필요합니다. 지금은 보호자가 링크에서 직접 동의하는 방식으로 대신하고 있습니다.
- **어디서**: 본인 확인·문자 인증 서비스 업체(예: 통신사 본인 확인 대행사, 문자 발송 서비스) — 어디를 쓸지 정해 주세요. 법률 검토 회신을 보고 꼭 필요한지 먼저 정해도 됩니다.
- **얼마나**: 가입·사업자 심사 수일~2주 (확인 필요).
- **끝났다는 신호**: 업체 화면에서 API 사용 승인.
- **막히면**: 해당 업체 영업·고객센터.
- 관련: P13-2b (blocked: "문자 인증 서비스 가입이 필요해 승인 범위 밖").

## 5. 카카오 로그인 (개발자 앱 키)
- **무엇을**: 카카오 개발자 앱을 만들고 REST API 키·Client Secret을 발급받아 Supabase 인증에 Kakao 로그인을 등록합니다. 이메일 동의 항목을 받으려면 비즈 앱 전환이 필요할 수 있습니다(확인 필요).
- **어디서**: developers.kakao.com → 내 애플리케이션 → 앱 추가 → 카카오 로그인 켜기·Redirect URI 등록 / Supabase 대시보드 → Authentication → Sign In / Providers → Kakao.
- **얼마나**: 키 발급은 당일. 비즈 앱 전환·동의 항목 심사가 필요하면 수일 (확인 필요).
- **끝났다는 신호**: Supabase Providers 화면에서 Kakao "Enabled". 알려 주시면 로그인 화면 버튼을 제가 확인합니다(`/auth/confirm` 콜백은 준비돼 있음).
- **막히면**: 카카오 개발자 데브톡(devtalk.kakao.com).
- 관련: P2-1K (blocked).

## 6. 카카오톡 채널·챗봇 관리자센터 (AI 상담)
- **무엇을**: 시범 샵(타타타렌탈샵)의 카카오톡 채널에 챗봇을 만들고, 스킬 주소(겨울파트너 웹훅)를 등록하고, 블록마다 콜백을 켭니다. 무료입니다. 샵마다 해야 하며, 샵 대표님 계정 권한이 필요합니다.
- **어디서**: 카카오 비즈니스 → 챗봇 관리자센터(chatbot.kakao.com) → 봇 만들기 → 스킬 → 시나리오 블록 설정 → 배포.
- **얼마나**: 채널·봇 만들기는 당일. 콜백 사용에 따로 신청 절차가 있는지는 확인 필요. 콜백은 봇 테스트가 아니라 **배포된 채널에서만** 동작합니다.
- **끝났다는 신호**: 실제 채널에서 손님처럼 질문 → 즉답 1건, 늦은 답(콜백) 1건, 사장님 넘김 1건 확인.
- **막히면**: 카카오 비즈니스 고객센터(챗봇 문의).
- 관련: P22-3(카카오 웹훅·`kakao-setup.md`는 그 작업에서 만듦), P22-8(시범).

## 7. 메일 발송 (Resend)·도메인
- **무엇을**: 가입 인증·비밀번호 재설정 메일이 스팸함에 빠지지 않게 발송 전용 서비스를 연결합니다. 회사 도메인이 없으면 먼저 삽니다.
- **어디서**: 도메인 구매처(가비아·후이즈·Cloudflare 등) → resend.com → Domains → DNS 레코드 넣기 → Supabase → Authentication → SMTP.
- **얼마나**: 30분 작업 + DNS 반영 몇 분~몇 시간.
- **끝났다는 신호**: Resend 도메인이 모두 "Verified", 테스트 가입 메일이 받은편지함에 도착. "메일 설정 끝"이라고 알려 주세요.
- **막히면**: Resend 지원(resend.com 도움말), 도메인 구매처 고객센터(DNS 화면).
- 관련: `docs/mail-setup.md` (단계별 설명 그대로 따라 하시면 됩니다).

## 8. 설문·인터뷰 (시범 샵 대표님)
- **무엇을**: 시범 샵 후보 대표님께 전속 강사 계약·원천징수·지급 주기·정산서 양식을 여쭙습니다. 답에 따라 입찰 상한, 패치 구매 주체, 벌점 점수, 전속 강사 3.3% 여부가 바뀔 수 있습니다.
- **어디서**: 대표님 방문·전화. 질문지는 `docs/owner-interview-guide.md`(질문 8개).
- **얼마나**: 한 분당 20~30분, 몇 분을 만나실지에 따라.
- **끝났다는 신호**: 답을 적은 메모를 저에게 주시면 설정·정산서 양식에 반영합니다.
- **막히면**: (사장님 직접 진행)
- 관련: P10-2 (blocked: "설문·인터뷰 결과가 있어야 반영 가능"), P19-1(전속 강사 지급 방식).

## 9. 시범 샵 섭외·온보딩
- **무엇을**: 시범 샵을 정하고, 샵 계정을 만들어 손님·강습 실데이터를 넣습니다. 대표님께는 `docs/pilot-onboarding.md`를 드리면 됩니다.
- **어디서**: 운영 주소(`https://winter-partner.vercel.app`) → 샵 등록·손님 카드·강습 등록.
- **얼마나**: 섭외는 사장님 일정, 샵 한 곳 입력 1~2시간.
- **끝났다는 신호**: 시범 샵이 실제 강습을 1건 이상 등록·배정.
- **먼저 할 것**: 2번(법률 검토 — 최소한 시범 전 필수 항목), 7번(메일), 10번(Pro 전환·백업), 14번(테스트 데이터 정리)을 끝낸 뒤가 안전합니다.
- 관련: P10-1 (blocked).

## 10. Supabase Pro 전환 + 인증 설정
- **무엇을**: 요금제를 Pro로 올리고(월 약 25달러, 자동 백업 때문에 추천), 그 김에 보안 설정을 켭니다.
  - 세션: Time-box 7일, Inactivity timeout 24시간 (P21-1)
  - 비밀번호: 최소 8자, Letters and digits, Secure password change 켜기, Email OTP 만료 900초, 유출 비밀번호 차단 켜기 (P21-2)
- **어디서**: Supabase 대시보드 → Organization → Billing(요금제) / Authentication → Sessions / Authentication → Sign In / Providers → Email / Authentication → Attack Protection.
- **얼마나**: 30분. 요금은 결제 전에 요금 페이지에서 다시 확인해 주세요.
- **끝났다는 신호**: Database → Backups에 첫 자동 백업이 보임. 알려 주시면 제가 설정을 읽기 전용으로 확인합니다.
- **막히면**: Supabase 지원(대시보드 오른쪽 위 도움말 → Support).
- 관련: `docs/security/checklist.md` 1·5항(P21-1, P21-2), `docs/backup-plan.md`.

## 11. Vercel 비밀값 넣기
- **무엇을**: AI 상담용 비밀값을 운영 환경변수에 넣습니다. **값은 저에게 보내지 마세요.**
  - 지금: `CONSULT_ENCRYPTION_KEY`(32바이트를 base64로 적은 값), `CONSULT_HASH_KEY`(32자 이상 무작위 문자열)
  - 나중에(P22-4 인스타 연결 때): `META_APP_ID`, `META_APP_SECRET`, `META_VERIFY_TOKEN`
- **어디서**: Vercel → 프로젝트 winter-partner → Settings → Environment Variables → 환경 **Production**만 체크.
- **얼마나**: 10분. 넣은 뒤 다시 배포해야 적용됩니다.
- **끝났다는 신호**: 목록에 이름이 보임(값은 가려짐). 한번 넣은 암호화 키는 바꾸면 기존 연락처를 못 읽으니 **바꾸지 마시고 따로 안전하게 보관**해 주세요.
- **막히면**: Vercel 지원(vercel.com/help).
- 관련: `docs/ai-consult/README.md` 사장님 결정 5.
