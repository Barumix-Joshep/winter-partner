## P2 (고치지 않음, 목록만)

1. **오류 화면 없음** — Supabase 장애·서버 오류 때 Next 기본 화면이 뜬다. "잠시 후 다시" 안내 화면(`error.tsx`) 필요.
2. **보안 헤더 없음** — CSP, X-Frame-Options(관리 화면 클릭재킹), HSTS, nosniff, Referrer-Policy.
3. **지난 시간·자정 넘는 강습** — 지난 시간 강습을 등록할 수 있고(직접 의뢰가 바로 만료돼 멈춤), 자정을 넘는 강습은 폼이 막는다.
4. **목록 쪽 나누기** — 강습 목록은 1000건 넘으면 잘리고, 손님 목록은 200명까지만 보이며 "더 있음" 표시가 없다.
5. **샵이 배정·강습을 표로 직접 고칠 수 있음** — 승인된 강습 시간을 다른 달로 옮기는 등. 이제 이중 정산은 색인이 막지만, 배정·강습 쓰기도 RPC 전용으로 줄이는 게 안전.
6. 팀원이 API로 공고 상한가(`jobs.instructor_rate`)는 볼 수 있다(팀 확정 금액은 아님).
7. 입찰과 선정이 같은 순간에 겹치면 이미 배정된 공고에 열린 입찰이 남을 수 있다(잠금 순서). 선정 때 전속 여부를 다시 보지 않는다.
8. 강사 지급액을 비우거나 0·음수로 RPC에 직접 넣는 경우를 막지 않는다. 아주 큰 금액은 원시 DB 오류가 뜬다.
9. 승인 뒤에도 샵 사장이 샵 유형·사업자번호를 바꿀 수 있다.
10. 웹푸시 실패 로그가 오류 객체 전체(구독 주소)를 남긴다.
11. npm audit 중간 9건(exceljs 하위 의존성, 서버에서만 엑셀 생성).
12. 두 탭에서 같은 손님을 등록하면 중복 손님이 생긴다(합치기 제안으로 정리 가능).
13. 390px: 샵 정산 요약 카드가 좁아 "690,000 원"이 두 줄, 강사 정산의 "팀 정산·승인 완료"가 글자 단위로 줄바꿈, 샵 상단 메뉴는 가로로 밀어야 "전속"이 보인다.

## 사장님이 승인·결정할 것

1. **위 마이그레이션 2개 원격 적용과 배포** (P19-1~P19-4 코드 푸시 포함).
2. **CSP 강제 전환 시점**: 운영에서 Report-Only로 하루 이상 돌려 위반이 없으면 `next.config.ts`의 `CSP_ENFORCE`를 켠다(코드 1줄, 배포 필요).
3. **전속 강사 지급 방식**: 대표님 인터뷰(`docs/owner-interview-guide.md`) 결과에 따라 샵이 직접 설정. 결과 전에는 모두 3.3% 그대로다.
4. **메일 서비스 가입과 Supabase SMTP 설정**(`docs/mail-setup.md`) — 사장님이 직접.
5. **백업 방식**(`docs/backup-plan.md`): Pro 전환(추천) 또는 매일 손 백업.
6. 이전부터 남은 것: 테스트 데이터 "삭제 승인", 약관·개인정보 처리방침 법률 검토, 실제 기기 점검(`docs/pilot-device-check.md`).

## 아직 못 한 것 (P2로 남김)

- 샵 **유형** 변경 요청 화면은 없다(본사 RPC·화면만 있음, 설정 화면은 사업자번호만 요청으로 돌림). 드물어서 본사에 문의하는 것으로 둔다.
- 지난 시간 강습 차단은 화면(서버 액션)에서만 한다. RPC를 직접 부르면 지난 시각도 들어간다(직접 의뢰는 응답 기한이 지나 멈출 뿐 돈에는 영향 없음).
- 화면에서 생긴 오류(클라이언트)는 오류 번호가 없다(서버 오류만 digest로 연결).
- 팀원이 API로 공고 상한가(`jobs.instructor_rate`)를 보는 것(P2 6), 두 탭 중복 손님(12), npm audit 중간 9건(11)은 그대로.

## 시범 샵을 받아도 되는 조건 (최신 의견)

돈 계산·권한·정산 무결성은 시범에 충분하다고 본다(P0·P1 0건, 정정·변경은 이력이 남는 절차로만). **아래가 끝나면 시범 샵 1~2곳을 받아도 된다.**
1. 마이그레이션 2개 적용·배포와 운영 스모크 통과
2. 메일 발송 설정과 가입·재설정 메일 수신 확인
3. 백업 방식 결정(Pro 전환 또는 매일 손 백업 시작)
4. 실제 기기에서 웹푸시·홈 화면 앱 확인(최소 아이폰 1·안드로이드 1)
5. 약관·개인정보 처리방침 법률 검토(재위탁 고지 포함)
6. 시범 샵 대표님과 전속 강사 지급 방식 확인(그 전까지는 3.3% 기본)
